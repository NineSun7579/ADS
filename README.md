本系统基于紫光同创FPGA+ARM异构架构，采用PG2L100H与PGL50H双FPGA协同设计，两片FPGA之间通过光口高速互联，实现多源视频数据的低时延传输与分布式处理。系统前端接入六路OV5640摄像头和一路HDMI视频输入，实现车身周围多视角环境感知。FPGA发挥并行算力优势，完成多路视频的同步采集、图像预处理与拼接融合，再通过PCIe高速接口与RK3568主控进行软硬件协同数据交互。该系统对行车环境内行人斑马线路障等目标能够准确识别且能够达到较高推理识别帧率，实现超速提醒、碰撞预警、变道辅助等ADAS功能，并针对夜间、强光等复杂路况做了感知优化。整套系统构成一套低延迟、高鲁棒性、可扩展的嵌入式车载多路辅助感知方案
